# Студия и гостиная 5980 × 3050

Интерактивная 3D-модель комнаты под домашнюю студию и гостиную: расстановка, акустика, список покупок.

**Открыть: https://pure-berg.github.io/remont-studio/**  
Сразу вкладка покупок: https://pure-berg.github.io/remont-studio/#buy · акустика: `#acoustics` · план: `#plan`

- `studio-room.html` — исходник (three.js с CDN)
- `index.html` — собранная самодостаточная страница, её отдаёт GitHub Pages
- `tools/build.sh` — сборка `index.html`
